Hormat (Inggil) Andhap (Merendah)
Bedanya Krama Inggil vs Andhap:
• Krama Inggil = untuk orang dihormati (orang lain). makan → dhahar, tidur → tilem, datang → rawuh, pergi → tindak
• Krama Andhap = untuk merendahkan diri sendiri ke orang hormat. saya → kula, memberi → nyaosi/caos, melihat → sumerep, datang → sowan
• Contoh andhap: saya memberi bapak → kula nyaosi bapak (bukan kula maringi)
• Contoh inggil: bapak makan → bapak dhahar (bukan mangan)
• Contoh both: saya memberi bapak yang sedang makan → kula nyaosi bapak ingkang dhahar
Uji cepat: ketik bapak makan → harusnya jadi dhahar. Ketik saya memberi bapak → harusnya jadi kula nyaosi bapak. Ketik saya datang ke rumah bapak → kula sowan dateng griyanipun bapak
Hover di tiap kata hasil untuk lihat aturan: -nya → -e (Bagongan), -kan → -ake, dll.
