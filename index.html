Materi Linguistik Murni Basa Bagongan Yogyakarta

🏛️ Pemurnian saking Surakarta

Aplikasi puniki sampun **100% dipun-resikaken saking kosakata Kedaton Surakarta** (kados tembung paran). Murni mung nggunakaken 11 kosakata khusus Bagongan Ngayogyakarta Hadiningrat lan bersifat sami-sami (egaliter).

👤 Pronomina Murni Bagongan Yogyakarta

  • Manira / Menira = Saya (Pronomina Tiyang I)
  • Pakenira / Pekenira = Kamu / Anda (Pronomina Tiyang II)

⚙️ Ater-ater Pasif `ka-` & Imbuhan

Ngetutake aturan Pranatan Sowan/Marak lan Basa Bagongan, wujud pasif murni nggunakaken ater-ater ka-:

Ater-ater Pasif `ka-` + Tembung Dasar Krama + Panambang Ngoko (`-ake`, `-e`)
Contoh: ka- + karsa + -ake = kakersakaké
