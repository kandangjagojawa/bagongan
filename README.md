# Aplikasi Bahasa Bagongan Keraton (GitHub Pages Ready)

Aplikasi web interaktif untuk mempelajari, menerjemahkan, dan menganalisis **Basa Bagongan** (sosiolek khas Keraton Yogyakarta & Surakarta).

## 🚀 Cara Deploy ke GitHub Pages:
1. Upload semua berkas di direktori ini (`index.html`, `style.css`, `app.js`, `dictionary.js`) ke repository GitHub Anda.
2. Buka **Settings** -> **Pages** pada repository GitHub Anda.
3. Pada bagian **Source**, pilih branch `main` (atau `master`) dan folder `/ (root)`.
4. Klik **Save**. Dalam 1-2 menit, aplikasi Anda akan online!

## 🌟 Fitur Utama:
- **Playground Penerjemah**: Indonesia -> Basa Bagongan dengan Bedah Struktur Kalimat (Grammar Inspector).
- **Ensiklopedia & Tata Bahasa**: Panduan lengkap aturan morfologi (Awalan Ngoko + Kata Dasar Krama) & filosofi Keraton.
- **Kamus Interaktif**: Pencarian kosakata Bagongan, Krama, Ngoko, dan Indonesia.
- **Kuis Interaktif**: Uji pemahaman laras bahasa Bagongan.
