# Aplikasi Basa Bagongan Keraton Ngayogyakarta Hadiningrat (Murni 100% Yogyakarta)

Aplikasi web interaktif versi Murni Keraton Ngayogyakarta Hadiningrat.
Sedaya kosakata lan aturan sampun disinkronaken kaliyan literatur resmi Keraton Yogyakarta (Balai Bahasa DIY).

## 📌 Penyelarasan Murni Yogyakarta (v3.0):
1. **Panghapusan Tembung Surakarta (`paran`)**: Tembung `paran` sampun dipun-ganti dados `punapa` (utawi `apa`) ngindhakaken aturan Murni Bagongan Ngayogyakarta.
2. **11 Tembung Khusus Bagongan Yogyakarta**:
   - Pronomina I: `manira` / `menira`
   - Pronomina II: `pakenira` / `pekenira`
   - Tanda Waktu/Papan: `samen` (sekarang), `besuk` (nanti/besok), `pundi` (mana)
   - Tembung Katrangan/Penunjuk: `puniki` (ini), `puniku` (itu), `enggeh` (ya), `mboten` (tidak), `santen` (berapa), `punapa` (apa).
3. **Morfologi Pasif `ka-`**: Nggunakaken awalan pasif `ka-` dipun-gabung kaliyan tembung dasar Krama lan panambang Ngoko (`-e`, `-ake`).

## 🚀 Cara Deploy menyang GitHub Pages:
1. Upload sedaya berkas ing direktori puniki (`index.html`, `app.js`, `dictionary.js`, `README.md`) teng repository GitHub panjenengan.
2. Buka **Settings** -> **Pages**.
3. Pilih branch `main` / `master` lan folder `/ (root)`.
4. Klik **Save**.
