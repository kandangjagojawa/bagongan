# Aplikasi Basa Bagongan Keraton Ngayogyakarta Hadiningrat (Versi Revisi Linguistik)

Aplikasi web interaktif untuk mempelajari, menerjemahkan, dan menganalisis **Basa Bagongan** khas Keraton Ngayogyakarta Hadiningrat secara akurat berdasarkan literatur Balai Bahasa DIY (Soepomo Poedjosoedarmo & Laginem).

## 📌 Koreksi Linguistik Utama (v2.0):
1. **Fokus Spesifik Basa Bagongan Yogyakarta**: Dipisahkan dari Basa Kedaton Surakarta. Bagongan bersifat *sami-sami* (egaliter) dengan 11 kosakata khusus.
2. **Koreksi Pronomina**: Kata ganti orang pertama mutlak `manira` / `menira`, dan orang kedua `pakenira` / `pekenira`. Kata `sira` dan `kula` dihapus dari kosakata khusus Bagongan.
3. **Morfologi Pasif `ka-`**: Menggunakan awalan pasif `ka-` (bukan `di-` atau `dipun-`), dipadukan dengan kata dasar Krama dan akhiran Ngoko (`-e`, `-ake`).
4. **Perspektif Sejarah**: Mencantumkan akar historis Basa Kedaton/Bagongan sejak era Mataram Islam & tradisi keraton terdahulu hingga dikodekan pada era Sri Sultan Hamengku Buwana I.

## 🚀 Cara Deploy ke GitHub Pages:
1. Upload semua berkas di direktori ini (`index.html`, `app.js`, `dictionary.js`, `README.md`) ke repository GitHub Anda.
2. Buka **Settings** -> **Pages** pada repository GitHub Anda.
3. Pada bagian **Source**, pilih branch `main` (atau `master`) dan folder `/ (root)`.
4. Klik **Save**.
