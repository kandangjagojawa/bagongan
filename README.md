# Aplikasi Basa Bagongan Keraton Ngayogyakarta Hadiningrat (Presisi 11 Tembung Khusus)

Aplikasi web interaktif Basa Bagongan Keraton Ngayogyakarta Hadiningrat berbasis 11 Tembung Khusus Otentik:
1. Henggeh (ya)
2. Mboya (tidak)
3. Manira / Menira (saya)
4. Pakenira / Pekenira (kamu)
5. Punapi / Ponapi (apa)
6. Puniki / Peniki (ini)
7. Puniku / Peniku (itu)
8. Wenten (ada)
9. Nedha / Neda (silakan / ayo)
10. Besaos (saja)
11. Seyos (lain / beda)

## 🚀 Deploy menyang GitHub Pages:
1. Upload sedaya berkas ing direktori puniki (`index.html`, `app.js`, `dictionary.js`, `README.md`) menyang repository GitHub.
2. Buka **Settings** -> **Pages**.
3. Pilih branch `main` / `master` lan folder `/ (root)`.
4. Klik **Save**.
